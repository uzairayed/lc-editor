# Window

Triggers: window, jali, lattice, pierced screen, someone looking out, light falling through a window.

## Intent

A window is a frame inside the frame. It either shows the view beyond or the pattern of the screen. Both need a moment to read; neither is a passing car.

## Hold

- Jali, lattice, or a composed view through the opening: **vista** if the view beyond is the point, **detail** if the screen pattern is the point.
- A window we walk past in a corridor: **breath**.
- Someone opening a window onto a place: treat as **reveal** only when the view that appears *is* the destination. Otherwise **breath**.

## Role

`site_detail` for pattern and light. `site_wide` when the window is how we first see the courtyard or landscape. Rarely `hook` (only a famous view through a known window).

## Cut

Enter when the opening is readable. Exit after the pattern or the view has landed. If both pattern and view matter, hold **vista** and skip a second window clip.

## Caption

Silent unless the view is a named place you have not named yet.

## Motion

Video: `none`. Still: `kenburns` toward the light. `punch` on the lattice, not on the empty glass.

## Done

The viewer has either read the pattern or stood in the view. Not both as two short clips.
