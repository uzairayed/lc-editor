# Scene index

Read a card only when a keyframe or shot contains that subject. Process is `context/HOW.md`.

## Thresholds

- **Door** (doorway, opening a door, hand on a handle) → `scenes/door.md`
- **Gate** (portal, entrance arch you walk or ride through) → `scenes/gate.md`
- **Window** (jali, lattice, someone looking out) → `scenes/window.md`
- **Stairs** (steps, climbing, descending) → `scenes/stairs.md`
- **Corridor** (hallway, arcade you walk down) → `scenes/corridor.md`
- **Courtyard** (open court, inner yard) → `scenes/courtyard.md`

## Monument

- **Facade** (building wide, tomb wide, the whole site from outside) → `scenes/facade.md`
- **Dome** (cupola, tomb roof) → `scenes/dome.md`
- **Tile** (mosaic, turquoise, glazed brick) → `scenes/tile.md`
- **Carving** (relief, inscription, knocker, plaque on stone) → `scenes/carving.md`

## Journey

- **Highway** (road, ride-by, overtake, traffic) → `scenes/highway.md`
- **Corner** (lean, turn, hairpin) → `scenes/corner.md`
- **Fuel** (pump, Cafe Imran, any planned stop on the route) → `scenes/fuel.md`
- **Sign** (place name, milestone, street board) → `scenes/sign.md`

## Table

- **Food** (plate, pour, stall, steam, chai) → `scenes/food.md`

## People

- **Hands** (making, pointing, touching the site) → `scenes/hands.md`
- **Crowd** (vendor, queue, prayer group, bystanders) → `scenes/crowd.md`

## Ride

- **Helmet** (visor, rider POV, mirrors) → `scenes/helmet.md`
- **Wheel** (tire, spokes, wheel-spin) → `scenes/wheel.md`
- **Two-up** (two helmet POVs, two N-5 wides, two overtake lanes at once) → `scenes/ride-pair.md`

## Place

- **Viewpoint** (overlook, mountain, snow field, forest edge) → `scenes/viewpoint.md`
- **Water** (lake, river, fountain, well) → `scenes/water.md`
- **Weather** (rain, fog, dust, mist) → `scenes/weather.md`
- **Sunset** (golden hour, dusk sky) → `scenes/sunset.md`
- **Night** (lamps, neon, lit streets) → `scenes/night.md`

## Pair

- **Pair** (two signs, two named walls, two plates of one kind, one beat then leave) → `scenes/pair.md`
- **Collage** (layout-heavy reel, stacked details, 2x2, caption-must) → `scenes/collage.md`

## Close

- **Texture** (stone grain, wood, fabric, rust, close material with no readable object) → `scenes/texture.md`
