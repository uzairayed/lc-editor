# Agent

Engine craft lives in `specs/craft.md`. It applies to every project.

Before the first `clip_add`, ask the owner (SPEC-SES-15) and store answers with `project_set`: subject, target duration, sound, caption density. Do not invent a series structure.

Karachi episode shape lives in `instructions.md` and applies only with `preset="karachi"`. Ride scene cards apply only when those subjects are in the keyframes.

Scene library: when you look at keyframes or set a clip's duration or role, follow `context/HOW.md`. Match subjects in `context/INDEX.md` and read only the matching cards. If nothing matches, use **ack**.

Two shots in one frame: `layout_add` (`specs/layouts.md`). Occasional pair → `context/scenes/pair.md`. Collage / mostly stacks / caption-must → `context/scenes/collage.md`.
